## Comments

2026-10-25: Built in `packages/astro/src/editor/`: pure checks in `limits.ts` (visible characters with `graphemeCount` from `@edity/core`, line Limits with the narrow value, number range and decimals, and whether a Field breaks a Limit as changed or as published), line measuring in `lines.ts` (rows of the text's client rects, on the element's own document), the watcher in `watch-limits.ts` and the counters in `Counters.tsx`. Every Field element is checked on each input, Draft change, focus change, resize of its block or the page (`ResizeObserver`), width change, narrow media query change and font load (`loadingdone`, `fonts.ready`; in WebKit the `ResizeObserver` is what catches fonts). A Field the Draft changed that breaks a Limit gets a red outline and `aria-invalid`, its counter shows the excess, and `state.overLimit` disables Publish; typing is never blocked. Built content over a Limit gets an amber outline and a counter ending "ya publicado así", and does not block Publish. The character counter shows from 80% on the focused Field; line counts show only when over, since a one-line Field is always at 100% of its lines. Narrow screens: the spec gives no breakpoint, so `edity({ narrowScreens })` takes a media query (use the Site's own phone-layout query, such as `'(max-width: 480px)'`) and defaults to `'(width < 600px)'`; it reaches the Editor in the page marker (`narrowScreens`). `limits.watch(document)` checks another same-origin document at its own width, for ticket 15's phone preview, which covers the preview half of L6; the width and font halves are tested here. `test/browser/editor-limits.spec.ts` covers L1 to L7 in all four projects (emoji, ZWJ sequences, flags, NFC and NFD accents; lines on a block and on an inline `<span>`; the 600 px switch; a late web font generated by `test/browser/wide-font.ts`), and removing the resize and font triggers makes the L2 and L6 tests fail. The fixture's `<h1>` is now `24ch` wide so its built title fits its 2-line Limit, and the isolation test compares the same Editor elements before and after hostile CSS, which can make more counters appear. Left over: a structural List Change makes all of that List's Fields count as changed (ticket 13 may want a finer rule), and the counters for the preview's own elements are ticket 15's.
